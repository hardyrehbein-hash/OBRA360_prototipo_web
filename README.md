# OBRA360 — Prototipo Web

Este es un prototipo estático navegable de OBRA360.

## Cómo verlo localmente
1. Descomprimir el ZIP.
2. Abrir `index.html` en cualquier navegador.

## Cómo publicarlo gratis en Netlify
1. Crear cuenta en Netlify.
2. Ir a “Add new site”.
3. Elegir “Deploy manually”.
4. Arrastrar la carpeta descomprimida completa.
5. Netlify entregará una URL gratuita tipo:
   `https://obra360-demo.netlify.app`
